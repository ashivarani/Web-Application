# 💳 Payment Gateway Integration – Donation Website

## 📌 Project Description

**Payment Gateway Integration** is a simple donation-themed web application developed using **HTML, CSS, and JavaScript**. The website is designed around the theme of the **National Defence Fund** and demonstrates the integration of a Razorpay payment button for online donations.

The application provides a user-friendly interface with Home, Donate, About, and Contact pages. Users can explore information about the cause and navigate to an externally hosted payment page using the integrated Razorpay button.

This project demonstrates fundamental web development concepts and basic third-party payment gateway integration.

## ✨ Features

- 🏠 **Home Page:** Displays an introduction to the National Defence Fund with a donation button.
- 💳 **Razorpay Integration:** Includes an embedded Razorpay payment button on the donation page.
- 💰 **Donation Navigation:** Allows users to access an externally hosted payment page.
- ℹ️ **About Page:** Provides information about the National Defence Fund.
- 📞 **Contact Page:** Displays email and social media links.
- 🧭 **Navigation Bar:** Provides navigation between Home, Donate, About, and Contact pages.
- 🎨 **Custom UI Design:** Uses CSS styling, background images, and interactive buttons.
- 🌐 **Static Website:** Runs directly in a web browser without requiring a backend server.

## 🚀 Installation and Setup

### Prerequisites

- A modern web browser such as Google Chrome, Microsoft Edge, or Firefox.
- An internet connection for loading the Razorpay payment button and external resources.

### Step 1: Download the Project

Download the repository ZIP file from GitHub and extract it.

### Step 2: Open the Project

Navigate to the extracted project folder.

### Step 3: Run the Website

Open `index.html` in a web browser.

The website launches without requiring additional installation or configuration.

## 📱 How to Use

1. Open the website using `index.html`.
2. View the home page containing information about the donation initiative.
3. Click **DONATE US** to navigate to the donation page.
4. Click **DONATE NOW** to access the Razorpay payment page, if the configured integration is available.
5. Navigate to **ABOUT** to read information about the National Defence Fund.
6. Visit **CONTACT** to access the provided email and social media links.

## ⚙️ How It Works

### 1. Home Page

The home page displays the website title, a message supporting soldiers, and a **DONATE US** button.

Clicking the donation button redirects users to `donate.html`.

### 2. Donation Page

The donation page integrates a Razorpay payment button using an externally loaded JavaScript script.

The embedded button links to a configured Razorpay-hosted payment page.

### 3. About Page

The About page presents information about the National Defence Fund and its purpose.

### 4. Contact Page

The Contact page provides links to:

- Email
- Twitter
- LinkedIn

### 5. Payment Gateway Integration

The website demonstrates integration with Razorpay through an embedded payment button.

Payment processing takes place through the external service rather than within the website itself.

## ⚠️ Current Limitations

- The website does not include a backend or database.
- Payment verification and transaction history are not implemented.
- The project does not independently generate payment receipts or confirmation emails.
- The configured Razorpay payment link has not been verified for current availability or ownership.
- Some page layouts use fixed dimensions and may require improvements for mobile responsiveness.
- This is an independent educational project and is not an official National Defence Fund website.
